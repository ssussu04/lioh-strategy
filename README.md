# LiOH STRATEGY V5.0

월별 조달·해외 정제공장 건설·통합 자금계획을 동시에 다루는 공급망 의사결정 앱입니다.

## V4.1 → V5 변경사항

1. **달성 시점 표시의 기준 통일**: 목표시점 지정 모드에서는 현재 선택된 MILP 계획의 월별 조달비율을 직접 검사해 *선택된 계획의 최초 지속 충족월*을 표시합니다. 다른 예산을 사용하는 별도 탐색 결과가 메인 화면의 성공 여부와 충돌하는 문제를 제거했습니다.
2. **최적해와 가능해 구분**: '최초 지속 충족월'은 현재 계획의 최초 시점이지 모든 가능한 계획 중 가장 빠른 시점은 아닙니다. 예산 지정 모드의 최단 시점 MILP도 최적성 증명 여부를 구분합니다.
3. **예산 수치 단위 명시**: 균등 배정액은 원/분기, 분기별 변동배정 총액은 전체 분석기간 누적액임을 명시합니다. 현재가치 총비용과 현금 유입 누적액도 서로 다른 지표입니다.
4. **시나리오 저장/복원 안내 정리**: JSON은 기업·공장·규제·예산 등의 *입력값만* 저장하며, 계산 결과는 Excel 또는 시각화 패키지로 별도 저장합니다.
5. **기존 기능 유지**: 10개 가용 공급기업, 기업별 공급 종료월과 최소 계약기간, 직접 편집·시드 생성, 공장 건설/가동, 최소보유현금, 2050년 이후 장기 기간, 통합 지도·간트차트, 균등/변동예산 MILP.

## Codespaces 실행

ZIP의 `PFE_Streamlit_V5` 폴더 안 파일을 저장소 최상위에 복사한 다음:

```bash
pip install -r requirements.txt
streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```

이미 사용 중인 포트면 다른 빈 포트를 이용하거나 기존 서버를 종료합니다. 이전 버전 실행 중인 터미널에는 새 명령을 붙여 넣지 말고 새 `bash` 터미널을 사용하세요.
